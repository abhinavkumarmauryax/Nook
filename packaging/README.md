# Nook on Linux

The server runs on Linux x64 as a self-contained binary; no Node.js is needed at runtime.

## Build the binary

On any machine with Node.js:

```bash
npm install
npm run build:linux      # produces ./nook-linux-x64 (ELF x86-64)
./nook-linux-x64         # setup UI on http://localhost:3000
```

### Flatpak

Requires `flatpak` and `flatpak-builder` with the Freedesktop SDK:

```bash
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak install -y flathub org.freedesktop.Platform//23.08 org.freedesktop.Sdk//23.08
flatpak-builder --force-clean --user build-dir packaging/io.github.abhinavkumarmauryax.Nook.yaml
flatpak-builder --user --install --force-clean build-dir packaging/io.github.abhinavkumarmauryax.Nook.yaml
flatpak run io.github.abhinavkumarmauryax.Nook
```

Note: a Flatpak runs sandboxed. To reach a Nook server on your LAN, the host
must allow inbound TCP on the chosen session port (default 3001).

## Firewall

Open the session port on the host:

```bash
sudo ufw allow 3001/tcp          # Debian/Ubuntu
sudo firewall-cmd --add-port=3001/tcp --permanent && sudo firewall-cmd --reload   # Fedora
```

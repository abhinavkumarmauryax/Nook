# Contributing to Nook

Thanks for your interest in improving the project.

## Before you start

- Read the [LICENSE](LICENSE). This is a source-available, non-commercial, contribution-only project — not an open-source licence.
- Contributions are accepted only through the [Official Repository](https://github.com/abhinavkumarmauryax/WatchTogetherParty).
- By submitting an issue or pull request you confirm that your contribution is your own original work, or that you have the necessary rights to submit it.

## Contributor Agreement

**A signed [Contributor Agreement](CONTRIBUTOR_AGREEMENT.md) is required before any contribution is accepted and merged.**

1. Open `CONTRIBUTOR_AGREEMENT.md`, fill in the sign-off details and include the acceptance line in your pull request description (or attach a signed copy as requested by the Project Owner).
2. Keep your copyright notice on any files you add.
3. Wait for review and an explicit merge. Submission does not guarantee acceptance.

The agreement keeps copyright ownership with you while granting the Project Owner the exclusive licence described in section 7 of the LICENSE to use the accepted contribution in the official project.

## How to contribute

1. Open an issue first for larger changes so the approach can be discussed.
2. Fork the repository (GitHub's native fork is permitted under section 9 of the LICENSE) and create a focused branch.
3. Make your change. Keep it small, documented and consistent with the existing style.
4. Test locally with `npm install && npm start`, then open `http://localhost:3000`.
5. Submit a pull request describing what changed and how you verified it, including your Contributor Agreement sign-off.

## Third-party material

If your contribution includes third-party libraries, assets or code, identify them and state their licence. Do not include material you do not have the right to submit. Third-party components stay under their own licences; this project's LICENSE does not override them.

## What not to submit

- Code or assets copied from unrelated projects without clear rights.
- DRM circumvention, scraping, or access-control bypasses.
- Changes that would enable commercial exploitation or independent distribution outside the LICENSE.

## Questions

Open an issue in the [Official Repository](https://github.com/abhinavkumarmauryax/WatchTogetherParty).
